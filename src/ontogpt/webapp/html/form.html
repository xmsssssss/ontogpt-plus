知识模板与本体对齐

模板定义可抽取的实体类别及其挂载的 OBO 国际本体库；对齐策略决定中文实体是否映射为标准英文本体 ID。

内置 60+ 领域模板，覆盖电力、临床、生物、生态、食品等场景；也可用 AI 自进化生成行业专属模板。

推荐项可将中文病历、规程与文献中的实体自动对齐到 MONDO / CHEBI / HP 等国际本体 ID。

模板自进化与增量学习 (Dynamic Schema Evolution)

开启后，引擎在抽取长文档切片时边进行边捕获未归类专有参数与指标，并在任务结束时自动提炼扩展模板字段，完成模式自进化。

长文档分块与并发性能

控制超长文档的切分粒度与并行度。窗口越大、并发越高，整体耗时越短，但单次请求的 Token 占用也越高。

增大窗口可把 48 万字文档的请求轮数从上百年降到几十次，显著压缩端到端耗时。

利用云端 API 的并发能力多块同时抽取，完成后自动按原文顺序合并知识图谱。
